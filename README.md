# Telegram Get ID Bot

A simple and elegant Telegram bot that retrieves chat and user IDs.

## Features

- **Private Chats**: Get your user ID
- **Group Chats**: Get both group ID and your user ID
- **Channels**: Get channel ID
- Clean, elegant UI with easy-to-copy IDs
- Reliable and lightweight

## Usage

1. Add the bot to any chat (private, group, or channel)
2. Send `/getids` command
3. Receive formatted ID information

## Commands

- `/start` - Welcome message with bot information
- `/getids` - Get ID information for the current chat

## Installation

```bash
# Clone the repository
git clone https://github.com/WonkaRed/Get-Id-Bot.git
cd Get-Id-Bot

# Install dependencies
npm install

# Run the bot
node bot.js
```

## Requirements

- Node.js (v12 or higher)
- npm
